# Nintendo - Game Boy/GBA/NDS (SkyEmu)

## Background

SkyEmu is a multi-system emulator, supporting Game Boy, Game Boy Color and Nintendo DS cores.

The SkyEmu core has been authored by

- Team SkyEmu

The SkyEmu core is licensed under

- MIT

A summary of the licenses behind RetroArch and its cores can be found [here](../development/licenses.md).

## Extensions

Content that can be loaded by the SkyEmu core have the following file extensions:

- .gb
- .gbc
- .gba
- .nds

RetroArch database(s) that are associated with the SkyEmu core:

- [Nintendo - Nintendo DS](https://github.com/libretro/libretro-database/blob/master/rdb/Nintendo%20-%20Nintendo%20DS.rdb)
- [Nintendo - Game Boy](https://github.com/libretro/libretro-database/blob/master/rdb/Nintendo%20-%20Game%20Boy.rdb)
- [Nintendo - Game Boy Advance](https://github.com/libretro/libretro-database/blob/master/rdb/Nintendo%20-%20Game%20Boy%20Advance.rdb)

## Core options

The SkyEmu core has the following option(s) that can be tweaked from the core options menu. The default setting is bolded.

#### System Settings

- **Core Override** [system_core_override] (**Automatic**|Game Boy|Game Boy Advance|Nintendo DS)

	Determines which core is used

- **Game Boy Firmware** [system_gb_bios_enable] (**ON**|OFF)

	Game Boy Firmware Enabled

- **Game Boy Advance Firmware** [system_gba_bios_enable] (**ON**|OFF)

	Game Boy Advance Firmware Enabled

- **Nintendo DS Firmware** [system_nds_bios_enable] (**ON**|OFF)

	Nintendo DS Firmware Enabled
