# Gong

## Background

A clone of Pong written for libretro.

The gong core has been authored by

- Brad Parker

The gong core is licensed under

- GPL v3

A summary of the licenses behind RetroArch and its cores can be found [here](../development/licenses.md).

## Extensions

Content that can be loaded by the gong core have the following file extensions:

- .gong

The gong core can also be started without content.

### Directories

The gong core's library name is 'gong'

## Core options

The gong core has the following option(s) that can be tweaked from the core options menu. The default setting is bolded.

- **Player 2** [gong_player2] (**CPU**|Human)

- **Video Refresh Rate (restart)** [gong_refresh] (**60**|70|72|75|100|119|120|140|144)

## Controllers

The gong core supports 2 port(s). Each can be set to one of the following device types:

- Joypad
