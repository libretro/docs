# Atari - 5200 (a5200)

## Background

a5200 is an Atari 5200 emulator based on Atari800 2.0.2, originally written for the GCW Zero. It is fast on low-powered hardware and aims to be plug and play: it has an open-source BIOS built in, and an on-screen keypad for the 5200 controller's twelve keys.

The a5200 core has been authored by

- Petr Stehlik
- zx81
- Alekmaul
- wavemotion-dave

The a5200 core is licensed under

- [GPLv2](https://github.com/libretro/a5200/blob/master/License.txt)

A summary of the licenses behind RetroArch and its cores can be found [here](../development/licenses.md).

## BIOS

The core has AltirraOS built in and runs without a BIOS. To use the original one, set the **BIOS** core option to **Official** and place it in RetroArch's system directory:

## Controllers

Port 1 can be one of two device types, set in `Controls > Port 1 Controls > Device Type`:

- **Atari 5200 Joystick (OSD Keypad)** - the default: L shows and hides an on-screen keypad, and A presses the highlighted key.
- **Atari 5200 Joystick (Direct Keypad Buttons)** - the keypad keys sit on RetroPad buttons instead.

Port 2 is a plain Atari 5200 joystick. The **Controller Hacks** option maps player 2 to player 1's right stick for the dual-stick games (*Robotron: 2084*, *Space Dungeon*), or swaps the ports for *Wizard of Wor*.
