# Infocom Z-Machine (MojoZork)

## Background

A Z-Machine emulator for playing text-based interactive fiction.

The mojozork core has been authored by

- Ryan C. Gordon

The mojozork core is licensed under

- zlib

A summary of the licenses behind RetroArch and its cores can be found [here](../development/licenses.md).

## Extensions

Content that can be loaded by the mojozork core have the following file extensions:

- .dat
- .z1
- .z3

RetroArch database(s) that are associated with the mojozork core:

- [Infocom - Z-Machine](https://github.com/libretro/libretro-database/blob/master/rdb/Infocom%20-%20Z-Machine.rdb)

### Directories

The mojozork core's library name is 'mojozork'

## Core options

The mojozork core has the following option(s) that can be tweaked from the core options menu. The default setting is bolded.

- **Visual style to use for gameplay** [style] (**Standard**|AppleII|MS-DOS|Commodore-64)

The mojozork core supports the following device type(s):
