# Sony - PocketStation (pokketstation)

## Background

An open-source Sony PocketStation emulator core, written in portable C. It is meant for reuse across a libretro core, a standalone Windows desktop app, and a PS Vita homebrew port. The emulator is stable, broadly tested by the community, and as cycle-accurate as possible. Loads and saves PlayStation memory card dumps.

The pokketstation core has been authored by

- mentalfoundry

The pokketstation core is licensed under

- GPLv3

A summary of the licenses behind RetroArch and its cores can be found [here](../development/licenses.md).

## Extensions

Content that can be loaded by the pokketstation core have the following file extensions:

- .mcr
- .mcs
- .pss
- .mcd
- .bin
- .gme

RetroArch database(s) that are associated with the pokketstation core:

- [Sony - PocketStation](https://github.com/libretro/libretro-database/blob/master/rdb/Sony%20-%20PocketStation.rdb)
