# Philips CDi (CDi 2015)

## Background

Based on the MAME codebase's Philips CDi emulation circa 2015, 'CDi 2015' is compatible with CDi games in CHD format from any MAME set. This core is designed to make it very easy to load these games. Names are irrelevant, hash lists aren't needed, just put the BIOS (again, from any MAME set) into the system directory, then load the game.

## Core options

The Philips CD-i 2015 core has the following option(s) that can be tweaked from the core options menu. The default setting is bolded.

- **Read configuration** [cdi2015_read_config] (**disabled**|enabled)

- **Auto save/load states** [cdi2015_auto_save] (**disabled**|enabled)

- **XY device (Restart)** [cdi2015_mouse_mode] (**none**|lightgun|mouse)

- **Enable throttle** [cdi2015_throttle] (**disabled**|enabled)

- **Enable cheats** [cdi2015_cheats_enable] (**disabled**|enabled)

- **Hide nag screen** [cdi2015_hide_nagscreen] (**disabled**|enabled)

- **Hide gameinfo screen** [cdi2015_hide_infoscreen] (**disabled**|enabled)

- **Hide warnings screen** [cdi2015_hide_warnings] (**disabled**|enabled)

- **Alternate render method** [cdi2015_alternate_renderer] (**disabled**|enabled)
