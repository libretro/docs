# Laserdisc arcade game (DirkSimple)

## Background

A player of laserdisc arcade games.

The dirksimple core has been authored by

- Ryan C. Gordon

The dirksimple core is licensed under

- zlib

A summary of the licenses behind RetroArch and its cores can be found [here](../development/licenses.md).

## Extensions

Content that can be loaded by the dirksimple core have the following file extensions:

- .ogv
- .dirksimple

## Features

Frontend-level settings or features that the dirksimple core respects.

| Feature           | Supported |
|-------------------|:---------:|
| States            | ✔         |
| Rewind            | ✔         |
| RetroArch Cheats  | ✕         |

### Directories

The dirksimple core's library name is 'dirksimple'

## Core options

The dirksimple core has no core options.

## Controllers

The dirksimple core supports the following device type(s):

- Generic game controller
