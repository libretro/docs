# PC/AT (My386)

## Background

My386 is a self-contained 386SX/DX IBM PC AT-compatible emulator for libretro, written in portable C11. The default machine is a 16 MHz 386SX with 4 MiB RAM, VGA/SVGA graphics and Sound Blaster 2.0 audio.

My386 supports real, protected and V86 modes, but does not emulate an x87 FPU.

## BIOS

SeaBIOS and SeaVGABIOS are built into the core. No BIOS files are required.

## Extensions

Content that can be loaded by the My386 core have the following file extensions:

- .img - a floppy or hard disk image
- .iso - a CD-ROM image
- .m3u - a playlist of disk images

## Loading content

- A standard floppy-sized **.img** is inserted in drive A:. Any other **.img** is attached as an IDE hard disk.
- An **.iso** is attached to the ATAPI CD-ROM drive. **CD-ROM Drive** must be enabled.
- An **.m3u** playlist can combine multiple floppy and CD images with one hard disk. Use RetroArch's disk controls to swap removable media.
- Use **Start Core** without content to boot the built-in SvarDOS hard disk. On first use, a writable copy is created at `<save directory>/my386/default-hdd.img`. **Writable Default Disk** controls whether changes to this copy persist.

Floppy and hard-disk images are opened read-write when the host allows it; ISO images are always read-only. CMOS/RTC settings are saved to `<save directory>/my386/cmos.bin`.

## Core options

The My386 core has the following option(s) that can be tweaked from the core options menu. The default setting is bolded.

### System

- **CPU Bus** [my386_cpu_bus] (**SX**|DX)
- **CPU Clock** [my386_cpu_clock] (12 MHz|**16 MHz**|20 MHz|25 MHz|33 MHz|40 MHz)
- **Installed RAM** [my386_ram] (1 MiB|2 MiB|**4 MiB**|8 MiB|16 MiB)
- **RAM Wait States** [my386_ram_wait_states] (0|**1**|2|3|4)
- **Motherboard Cache** [my386_cache] (**Enabled**|Disabled)
- **VBE Linear Framebuffer** [my386_lfb] (**Banked VBE only**|High linear framebuffer (DX only))
- **CD-ROM Drive** [my386_cdrom] (**Enabled**|Disabled)
- **Sound Blaster 2.0** [my386_sb2] (**Enabled**|Disabled)
- **Floppy Drive Timing** [my386_floppy_timing] (**Realistic**|Off (USB/passthrough drives))
- **Serial Port** [my386_serial] (**COM1 (3F8h, IRQ4)**|COM2 (2F8h, IRQ3)|Disabled)
- **Game Port** [my386_gameport] (**1 joystick (2 buttons)**|2 joysticks (2 buttons each)|4-button flight stick|Disabled)

Restart content after changing System options, except **CPU Clock**, which applies on the next reset.

### Frontend

- **Writable Default Disk** [my386_default_disk_writable] (**Enabled**|Disabled)
- **Primary Media Format** [my386_primary_media] (**Floppy**|CD)
- **Performance Warning** [my386_performance_warning] (**Enabled**|Disabled)

Frontend options need no restart. **Primary Media Format** selects which removable drive is ejected when both floppy and CD media are present.

## Device types

The My386 core takes input from the keyboard; enable RetroArch's Game Focus mode (Scroll Lock) to type. A mouse is emulated as a PS/2 mouse. RetroPads provide game-port joysticks, with the layout selected by **Game Port**.
