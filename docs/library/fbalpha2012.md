# Arcade (FB Alpha 2012)

## Background

Based on a snapshot of the Final Burn Alpha codebase from circa 2012, 'FB Alpha 2012' is compatible with FB Alpha v0.2.97.29 ROM sets. Most users should use up-to-date FBNeo instead and should only fall back to this core if their device is not capable of running that core.

The FB Alpha 2012 core has been authored by

- Team FB Alpha

## Extensions

Content that can be loaded by the FB Alpha 2012 core have the following file extensions:

- .iso
- .zip
- .7z

## Core options

The FB Alpha 2012 core has the following option(s) that can be tweaked from the core options menu. The default setting is bolded. These options are set when content is loaded. **Diagnostic Input** is only shown for games that have a diagnostic input, and **Neo Geo mode** only for Neo Geo games. Each game's DIP switches are added as further options.

- **Core-provided aspect ratio** [fbalpha2012_aspect] (**DAR**|PAR)

- **CPU overclock** [fbalpha2012_cpu_speed_adjust] (**100**|110|120|130|140|150|160|170|180|190|200)

- **Diagnostic Input** [fbalpha2012_diagnostic_input] (**None**|Hold Start|Start + A + B|Hold Start + A + B|Start + L + R|Hold Start + L + R|Hold Select|Select + A + B|Hold Select + A + B|Select + L + R|Hold Select + L + R)

- **Hiscores** [fbalpha2012_hiscores] (**enabled**|disabled)

- **Neo Geo mode** [fbalpha2012_neogeo_mode] (**MVS**|AES|UNIBIOS|DIPSWITCH)
