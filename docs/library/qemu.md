# QEMU

## Background

A port of the QEMU emulator to libretro.

The QEMU core has been authored by

- QEMU devs
- io12

The QEMU core is licensed under

- GPLv2

A summary of the licenses behind RetroArch and its cores can be found [here](../development/licenses.md).

## Extensions

Content that can be loaded by the QEMU core have the following file extensions:

- .qemu_cmd_line
- .iso
- .img
- .qcow
- .qcow2

## Features

Frontend-level settings or features that the QEMU core respects.

| Feature           | Supported |
|-------------------|:---------:|
| Saves             | ✕         |

| Rewind            | ✕         |

| [Memory Monitoring (achievements)](../guides/memorymonitoring.md) | ✕         |

| Controls          | ✕         |
| Subsystem         | ✕         |
| Disk Control      | ✕         |

## Core options

The QEMU core has no core options.
