# Elektronika Inženjering - Galaksija (Galaksija)

## Background

Galaksija (Galaxy) was a low-cost home computer released in 1983 in the former Yugoslav countries as a build-it-yourself kit. The design, which was based on the Zilog Z80A CPU, was later mass produced for distribution to schools.

The galaksija core has been authored by

- nikp123

## Extensions

Content that can be loaded by the galaksija core have the following file extensions:

- ..gal

The galaksija core can also be started without content.
