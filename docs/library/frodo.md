## Extensions

Content that can be loaded by the Frodo core have the following file extensions:

- .d64
- .t64
- .x64
- .p00
- .lnx
- .lyx
- .zip

RetroArch database(s) that are associated with the Frodo core:

- [Commodore - 64](https://github.com/libretro/libretro-database/blob/master/rdb/Commodore%20-%2064.rdb)

### Directories

The Frodo core's library name is 'Frodo'

## Core options

The Frodo core has the following option(s) that can be tweaked from the core options menu. The default setting is bolded.

- **Internal Resolution** [frodo_resolution] (**384x288**|400x300|640x480|832x576|960x720|1024x768|1024x1024)
