# Nintendo - DS (NooDS)

## Background

Unofficial libretro port of NooDS, the speedy DS emulator

The NooDS core has been authored by

- Hydr8gon
- Jonian Guveli

The NooDS core is licensed under

- GPLv3

A summary of the licenses behind RetroArch and its cores can be found [here](../development/licenses.md).

## Extensions

Content that can be loaded by the NooDS core have the following file extensions:

- .nds
- .gba

The NooDS core can also be started without content.

RetroArch database(s) that are associated with the NooDS core:

- [Nintendo - Nintendo DS](https://github.com/libretro/libretro-database/blob/master/rdb/Nintendo%20-%20Nintendo%20DS.rdb)
- [Nintendo - Nintendo DS (Download Play)](https://github.com/libretro/libretro-database/blob/master/rdb/Nintendo%20-%20Nintendo%20DS%20(Download%20Play).rdb)

## Core options

The NooDS core has the following option(s) that can be tweaked from the core options menu. The default setting is bolded.

- **Direct Boot** [noods_directBoot] (**enabled**|disabled)

- **FPS Limiter** [noods_fpsLimiter] (**disabled**|enabled)

- **Keep ROM in RAM** [noods_romInRam] (**disabled**|enabled)

- **Threaded 2D** [noods_threaded2D] (**enabled**|disabled)

- **Threaded 3D** [noods_threaded3D] (**1 Thread**|2 Threads|3 Threads|4 Threads|Disabled)

- **High Resolution 3D** [noods_highRes3D] (**disabled**|enabled)

- **Screen Arrangement** [noods_screenArrangement] (**Automatic**|Vertical|Horizontal|Single Screen)

- **Screen Rotation** [noods_screenRotation] (**Normal**|Rotated Left|Rotated Right)

- **Screen Sizing** [noods_screenSizing] (**Even**|Enlarge Top|Enlarge Bottom)

- **Screen Position** [noods_screenPosition] (**Center**|Top|Bottom|Left|Right)

- **Screen Gap** [noods_screenGap] (**None**|Quarter|Half|Full)

- **Crop GBA Screen** [noods_gbaCrop] (**enabled**|disabled)

- **Screen Filter** [noods_screenFilter] (**Nearest**|Upscaled|Linear)

- **Simulate Ghosting** [noods_screenGhost] (**disabled**|enabled)

- **Swap Screen Mode** [noods_swapScreenMode] (**Toggle**|Hold)

- **Touch Mode** [noods_touchMode] (**Auto**|Pointer|Joystick|None)

- **Show Touch Cursor** [noods_touchCursor] (**enabled**|disabled)

- **Microphone Input Mode** [noods_micInputMode] (**Silence**|Noise|Microphone)

- **Microphone Button Mode** [noods_micButtonMode] (**Toggle**|Hold|Always)
