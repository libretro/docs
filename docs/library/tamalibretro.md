# Bandai - Tamagotchi P1 (TamaLIBretro)

## Background

A port of the TamaLIB emulator for first-generation Tamagotchi handhelds to libretro.

The TamaLIBretro core has been authored by

- Jean-Christophe Rona, Keith Bourdon

The TamaLIBretro core is licensed under

- GPL-2.0

A summary of the licenses behind RetroArch and its cores can be found [here](../development/licenses.md).

## Extensions

Content that can be loaded by the TamaLIBretro core have the following file extensions:

- .b
- .rom
- .bin

## Features

Frontend-level settings or features that the TamaLIBretro core respects.

### Directories

The TamaLIBretro core's library name is 'TamaLIBretro'

## Core options

The TamaLIBretro core has no core options.

## Controllers

The TamaLIBretro core supports the following device type(s):

- Tamagotchi
