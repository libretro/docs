# Arcade (MAME 2015)

## Background

Based on a snapshot of the MAME codebase circa 2015, 'MAME 2015' is compatible with MAME 0.160 ROM sets. MAME is the most compatible emulator in the world, and it can run almost any game from any platform (though running console games through this core requires additional steps). If your device can run the up-to-date MAME - Current core (or any other newer snapshot) at full speed, most users will have a better experience with that core, while FBNeo is typically a better choice for speed vs accuracy, as long as it supports the game(s) in question.

## Core options

The MAME 2015 core has the following option(s) that can be tweaked from the core options menu. The default setting is bolded.

- **Read configuration** [mame2015_read_config] (**disabled**|enabled)

- **Auto save/load states** [mame2015_auto_save] (**disabled**|enabled)

- **XY device (Restart)** [mame2015_mouse_mode] (**none**|lightgun|mouse)

- **Enable throttle** [mame2015_throttle] (**disabled**|enabled)

- **Enable cheats** [mame2015_cheats_enable] (**disabled**|enabled)

- **Hide nag screen** [mame2015_hide_nagscreen] (**disabled**|enabled)

- **Hide gameinfo screen** [mame2015_hide_infoscreen] (**disabled**|enabled)

- **Hide warnings screen** [mame2015_hide_warnings] (**disabled**|enabled)

- **Alternate render method** [mame2015_alternate_renderer] (**disabled**|enabled)

- **Boot to OSD** [mame2015_boot_to_osd] (**disabled**|enabled)

- **Boot from CLI** [mame2015_boot_from_cli] (**disabled**|enabled)
