# Arcade (FB Alpha 2012 CPS-3)

## Background

Based on a snapshot of the Final Burn Alpha codebase from circa 2012, 'FB Alpha 2012 CPS-3' is compatible with FB Alpha v0.2.97.29 ROM sets. This core variant is for CPS-3 games only. It exists solely for use with RAM-constrained platforms, such as certain console or embedded platforms, that do not have the capacity to load the full core along with large games. Most users should use up-to-date FBNeo instead.

## Core options

The FB Alpha 2012 CPS-3 core has the following option(s) that can be tweaked from the core options menu. The default setting is bolded.

- **Core-provided aspect ratio** [fbalpha2012_cps3_aspect] (**DAR**|PAR)

- **Frameskip** [fbalpha2012_cps3_frameskip] (**0**|1|2|3|4|5)

- **CPU overclock** [fbalpha2012_cps3_cpu_speed_adjust] (**100**|110|120|130|140|150|160|170|180|190|200)

- **P1 control scheme** [fbalpha2012_cps3_controls_p1] (**gamepad**|arcade)

- **P2 control scheme** [fbalpha2012_cps3_controls_p2] (**gamepad**|arcade)

- **Hiscores** [fbalpha2012_cps3_hiscores] (**enabled**|disabled)

- **Samplerate (need to quit retroarch)** [fbalpha2012_cps3_samplerate] (**48000**|44100|32000|22050|11025)

- **L/R P1 gamepad scheme** [fbalpha2012_cps3_lr_controls_p1] (**normal**|remap to R1/R2)

- **L/R P2 gamepad scheme** [fbalpha2012_cps3_lr_controls_p2] (**normal**|remap to R1/R2)
