# Atari Lynx Core Compatibility

RetroArch has four Atari Lynx cores. Rather than keeping a game list here that goes stale, per-game problems are tracked on each core's issue tracker. If a game misbehaves, check there first, and file a report if it is not listed.

| Core | Issue tracker |
|------|---------------|
| [Beetle Lynx](../beetle_lynx.md) | [libretro/beetle-lynx-libretro](https://github.com/libretro/beetle-lynx-libretro/issues) |
| [Gearlynx](../gearlynx.md) | [drhelius/Gearlynx](https://github.com/drhelius/Gearlynx/issues) |
| [Handy](../handy.md) | [libretro/libretro-handy](https://github.com/libretro/libretro-handy/issues) |
| [Holani](../holani.md) | [LLeny/holani-retro](https://github.com/LLeny/holani-retro/issues) |

## Known issues

| Core | Game | Issue |
|------|------|-------|
| Beetle Lynx | RoadBlasters | Graphics glitches: minor flickering and glitches after starting a race. |
| Handy | RoadBlasters | Graphics glitches: minor flickering and glitches after starting a race. |

Gearlynx and Holani are newer cores and have no entries here; see their trackers above.
