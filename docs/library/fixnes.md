# Nintendo - NES / Famicom (fixNES)

## Background

An alpha-stage emulator written as a learning experience, fixNES is a good, simple core for learning how NES emulators are written, but it's not a good choice for general use. Individuals who are looking for a feature-complete, accurate, easily-usable emulator should look instead to Mesen, Nestopia or FCEUmm, depending on their use-case.

## Extensions

Content that can be loaded by the fixNES core have the following file extensions:

- .nes
- .fds
- .qd
- .nsf

RetroArch database(s) that are associated with the fixNES core:

- [Nintendo - Nintendo Entertainment System](https://github.com/libretro/libretro-database/blob/master/rdb/Nintendo%20-%20Nintendo%20Entertainment%20System.rdb)
- [Nintendo - Family Computer Disk System](https://github.com/libretro/libretro-database/blob/master/rdb/Nintendo%20-%20Family%20Computer%20Disk%20System.rdb)
