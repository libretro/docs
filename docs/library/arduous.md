# Arduboy (Arduous)

## Background

Arduboy emulator implemented as a libretro core.

The arduous core has been authored by

- James Roeder

The arduous core is licensed under

- GPLv3

A summary of the licenses behind RetroArch and its cores can be found [here](../development/licenses.md).

## Extensions

Content that can be loaded by the arduous core have the following file extensions:

- .hex

RetroArch database(s) that are associated with the arduous core:

- [Arduboy Inc - Arduboy](https://github.com/libretro/libretro-database/blob/master/rdb/Arduboy%20Inc%20-%20Arduboy.rdb)
